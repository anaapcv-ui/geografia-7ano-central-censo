Leia e escreva com suas palavras, estação por estação.

Quiz

🗺️

Simulado

26 questões no estilo da prova, com gabarito comentado.

📌 Como usar este material

  1. 📖 Leitura Guiada — leia cada estação e escreva as respostas. Escrever com as próprias palavras é o que fixa o conteúdo.
  2. 🎯 Quiz — teste na hora o que aprendeu, enquanto está fresco.
  3. 🗺️ Resumo — use as fichas para reforçar exatamente o que o Quiz mostrou que precisa melhorar.
  4. 📝 Simulado — só depois, enfrente as 26 questões valendo, como se fosse a prova.
👩‍👦 Dica para a mãe/responsável: ao terminar o Quiz e o Simulado, aparece um código (MED-… e SIM-…). Peça esse código ao seu filho(a) para liberar o gabarito comentado — assim você confere se ele realmente fez, e não só espiou as respostas.

📊 Relatório para os pais

Digite um código para ver o progresso: o MED-… do Quiz, o SIM-… do Simulado, ou o código fixo da família PAIS-77.
